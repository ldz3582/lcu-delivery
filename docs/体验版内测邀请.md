# 体验版内测：怎么把别人「拉进来」看

> 先分清两张码，这是最容易踩的坑：
>
> | | 预览二维码（`dist/预览二维码.png`） | 体验版二维码 |
> | --- | --- | --- |
> | 怎么来 | 开发者工具「预览」/ `publish-wechat.sh preview` | 上传代码 → 后台「选为体验版本」→ 下载 |
> | 有效期 | **25 分钟** | **7 天**（2025 年底新规） |
> | 谁能扫 | 默认只有开发者/项目成员；体验成员要管理员单独开「查看开发版」 | 名单里的**体验成员** |
> | 能不能发人 | ❌ 发出去大概率「无法打开」 | ✅ 这才是发给别人的那张 |
>
> 所以「让别人看」= 上传 → 选为体验版 → 加体验成员 → 发体验版二维码。四步，缺一步都打不开。

---

## 1. 一次性准备：把代码变成「开发版本」

需要两样东西，都在小程序后台：

1. **上传密钥**：开发管理 → 开发设置 → 小程序代码上传 → 生成 → 下载 `private.wxXXXX.key`（只给一次，丢了重新生成）
2. **IP 白名单**：同一页往下，填本机公网 IP（`curl -s https://api.ipify.org`），不填上传必报 `40164`

然后：

```bash
cd ~/Downloads/coderworks/外卖小程序/lcu-delivery
./ops/publish-wechat.sh upload ~/Downloads/private.wx你的AppID.key 1.0.0 "内测第一版"
```

没有密钥文件，就在微信开发者工具里点右上角「上传」——效果一样，都是把代码送到后台的「开发版本」。

## 2. 后台：选为体验版 + 拿二维码

1. <https://mp.weixin.qq.com> → **管理 → 版本管理 → 开发版本**
2. 找到刚上传的版本 → 右侧「…」→ **选为体验版本**
3. 同页「体验版本」区域 → **二维码** → 下载/截图

这张二维码 7 天有效，到期回这里重新下载即可（体验版本身不会因为过期消失）。

> 也可以扫「体验版」旁边的小程序码直接进，但发人还是发图片最省事。

## 3. 加人：把对方加进「体验成员」

**后台 → 用户身份 → 成员管理 → 体验成员 → 添加 → 输入对方微信号 → 确定**

- 立即生效，**不需要对方点同意**，加完他就能扫
- 只能按**微信号**搜，不能按昵称/手机号；让对方在 微信 → 我 → 设置 → 账号与安全 里看自己的微信号
- 管理员和项目成员都能加，不用非得管理员操作
- 名单里的人，扫体验版码 → 打开的是**体验版**；名单外的人扫 → 提示未开放

名额上限（按主体类型）：

| 主体 | 体验成员上限 |
| --- | --- |
| 个人 | 15 |
| 未认证、未发布 非个人 | 30 |
| 已认证未发布 / 未认证已发布 非个人 | 60 |
| 已认证已发布 非个人 | 90 |

另外每个微信号最多当 50 个小程序的体验成员。

## 4. 转发给对方的原话（可直接复制）

> 帮我测下「聊大外卖」内测版，扫这个码 👇
>
> 1. 微信扫一扫 / 长按识别二维码
> 2. 打开后点右上角 **「…」→「打开调试」**，小程序会重启一次（不做这步会报「不在以下 request 合法域名列表中」）
> 3. 回到首页，用**学号登录**（6~20 位字母数字，随便填，首次自动注册，密码也随便设）
> 4. 商家/骑手端同理，登录页选身份即可
>
> 打不开先别急，把**微信号**发我，我这边把你加进体验名单再扫。

## 5. 打不开的排查表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「该小程序未开放」/ 没权限 | 不在体验成员名单，或加错号 | 后台加名单，让对方重新扫码（1 分钟内生效） |
| 提示「无法打开」「已过期」 | 用了预览二维码（25 分钟）或体验版码超过 7 天 | 回后台重新下载体验版二维码 |
| 报「不在以下 request 合法域名列表中」 | 没点「打开调试」 | 右上角 … → 打开调试 → 退出重进 |
| 白屏 / 一直转圈 / 接口 500 | 后端不可达：换了 Wi-Fi、隧道重启、后端没起 | `./ops/tunnel.sh url` 看当前地址；地址变了要 `./ops/tunnel.sh rebuild` + 重新上传 |
| 登录报「未配置小程序 AppID/AppSecret」 | `.env` 里 `WX_USER_*` 是空的，走了 mock 登录之外的分支 | 用学号登录；要开微信登录跑 `./ops/use-wechat.sh` |
| 只能扫一次，第二次打不开 | 扫的是「预览」码 | 换体验版二维码 |

## 6. 想让「谁都能扫」

做不到。体验版**永远只对名单内的人开放**，而且有名额上限。

要公开访问只有一条路：**提交审核 → 发布正式版**，前置条件是已备案域名 + HTTPS（`docs/发布微信小程序.md` 路线 B）。体验版的定位就是 10~20 人内测。
