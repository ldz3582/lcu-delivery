# 接入微信公众平台（小程序）操作手册

从 0 到「微信里能打开自己的小程序、能拿到真实 openid」的完整步骤。
代码这边已经准备好了：你只需要拿 AppID/AppSecret，然后跑一条命令。

---

## 一、先决定：用什么主体注册

这一步决定你**能不能收钱**。

| 主体 | 能做什么 | 不能做什么 | 建议 |
| --- | --- | --- | --- |
| 个人 | 注册小程序、微信登录、定位、订阅消息 | **不能开通微信支付**、不能选「餐饮/外卖」等需要资质的类目 | 只能做演示，不能真收钱 |
| 个体工商户 | 支付、餐饮类目（凭《食品经营许可证》或小餐饮登记证） | —— | 起步最快，成本低 |
| 企业 | 支付、分账、平台类目、开票 | 需要营业执照 + 对公户 | 要接分账、给商家/骑手结算，必须企业 |

**结论**：要真跑外卖（收钱 + 给商家骑手分账），至少要个体工商户，推荐有限公司。

---

## 二、注册小程序（约 15 分钟）

1. 打开 https://mp.weixin.qq.com → 右上角「立即注册」→ 选「小程序」。
2. 填**一个从没注册过微信公众平台的邮箱**（QQ 邮箱、163 都行），收激活邮件。
3. 主体类型选「企业」或「个体工商户」：
   - 企业：营业执照照片、法人身份证、对公账户信息
   - 个体户：营业执照、经营者身份证
4. 用**管理员本人微信**扫码，绑定为管理员（后面登录、改配置都要这个微信）。
5. 完成后进入后台，你会看到自己的 AppID。

> 没营业执照也能先走「个人」注册把代码跑通，等执照下来再迁移——但个人主体的小程序**不能改主体**，只能重新注册一个企业小程序。所以如果只是临时验证，建议先用我们的本地 mock 模式，别急着注册个人主体。

---

## 三、拿 AppID 和 AppSecret

后台路径：**开发管理 → 开发设置 → 开发者 ID**

| 字段 | 用途 | 注意 |
| --- | --- | --- |
| AppID | 小程序唯一标识，前端和后端都要 | 可以公开 |
| AppSecret | 后端换 openid / 发消息用 | **只显示一次**，泄露要立刻重置 |

同一个页面往下还有 **服务器域名**（第 6 节用）和 **IP 白名单**（如果后端要调 `access_token` 接口，需要把服务器公网 IP 加进去）。

工作台（商家/骑手）如果也做成独立小程序，就再注册一个，拿第二个 AppID；
不想注册两个，可以先共用同一个 AppID，代码这边已经支持两种方式。

---

## 四、一条命令接进项目

在项目根目录（`~/lcu-delivery`）执行：

```bash
cd ~/lcu-delivery

# 只注册了一个小程序
./ops/use-wechat.sh wx你的AppID 你的AppSecret

# 商家/骑手工作台单独注册了小程序
./ops/use-wechat.sh wx用户端AppID 用户端Secret wx工作台AppID 工作台Secret
```

这条命令会自动做 6 件事：

1. 调微信接口校验 AppID/AppSecret 是否正确（返回 `40029` 说明凭据没问题，只是测试 code 无效）；
2. 写入 `ops/.env`（`WX_USER_APPID` / `WX_USER_SECRET`）；
3. 改两个小程序的 `src/manifest.json` 里的 `appid`；
4. 重新构建两个小程序产物；
5. 带凭据重启后端；
6. 调一次真实登录接口，确认后端已经不再报「未配置」。

**验证成功的标志**：

```bash
curl -s -X POST http://127.0.0.1:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"code":"fake"}'
# 返回 40129/40029 一类的「code 无效」= 凭据有效
# 返回「后端未配置小程序 AppID/AppSecret」= 没接上
```

## 五、微信开发者工具（本机联调）

1. 下载 macOS ARM 版：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 用**管理员或被添加为开发者**的微信扫码登录（开发者要在后台「成员管理」里加）。
3. 导入项目，目录选：
   - 统一小程序（用户/商家/骑手）：`~/lcu-delivery/apps/lcu-mobile/dist/build/mp-weixin`
4. 工具栏「详情 → 本地设置」勾选 **不校验合法域名**（本地阶段必须勾，否则 `http://127.0.0.1:8080` 被拦）。
5. 点「真机预览」扫码，就能在自己手机上打开。

此时登录会走真实链路：`uni.login` 拿 code → 后端 `jscode2session` → 拿到真实 openid → 建用户 → 发 token。
浏览器 H5 里没有微信环境，会自动回退到模拟登录（这套降级逻辑已经写好）。

> 开发者工具的「服务端口」要打开（设置 → 安全设置），`miniprogram-ci` 上传和 CLI 预览都依赖它。

## 六、真机/线上必须做的事：域名 + 备案

微信小程序**不允许请求 IP**，必须是已备案的域名且 HTTPS，并加到后台白名单。

| 步骤 | 做什么 | 周期 |
| --- | --- | --- |
| 1 | 买域名（腾讯云/阿里云），如 `lcu-food.com` | 即时 |
| 2 | ICP 备案（云厂商代备案，要营业执照/身份证） | 1–20 个工作日 |
| 3 | 配 HTTPS 证书（云厂商免费 DV 证书即可） | 即时 |
| 4 | 解析 `api.lcu-food.com` 到服务器 | 即时 |
| 5 | 后台 **开发管理 → 开发设置 → 服务器域名**：request / uploadFile / downloadFile 都填 `https://api.lcu-food.com` | 即时 |
| 6 | 小程序 `VITE_API_BASE` 改成 `https://api.lcu-food.com` 后重新构建 | 即时 |

本地/内网穿透（cpolar、ngrok）的域名不能备案，只适合开发阶段，且要在开发者工具里关掉域名校验；真机预览想连本地后端，把手机和电脑放同一个 Wi-Fi，API 换成电脑局域网 IP（`apps/lcu-mobile` 下复制 `.env.example` 为 `.env`，改 `VITE_API_BASE`，重新构建）。

## 七、上线前还差的 5 件事

| # | 事项 | 在哪做 | 说明 |
| --- | --- | --- | --- |
| 1 | 微信认证 | 后台 设置 → 微信认证 | 300 元/年，认证后才能用支付等高级能力 |
| 2 | 服务类目 | 后台 设置 → 基本设置 → 服务类目 | 一期选「餐饮服务 → 餐饮服务场所/餐饮服务管理企业」；资质见主手册 2.3 |
| 3 | 小程序备案 | 后台 设置 → 基本设置 → 小程序备案 | 2023-09 起强制，未备案不能发布 |
| 4 | 隐私保护指引 | 后台 设置 → 服务内容声明 | 必须勾选：位置、相册、手机号、**剪贴板**（粘贴解析会读剪贴板） |
| 5 | 提审材料 | 版本管理 → 提交审核 | 必须给可登录的测试账号，否则必被拒 |

微信支付（商户号 + 分账）是另一条线，见主手册 2.4，需要企业主体 + 对公户。

## 八、常见错误码

| errcode | 含义 | 解决 |
| --- | --- | --- |
| 40013 | AppID 无效 | 复制不完整 / 小程序被注销 |
| 40125 | AppSecret 无效 | 后台重置 Secret 后重新跑 `use-wechat.sh` |
| 40029 | code 无效 | 正常：code 只能用一次、5 分钟过期；真机重新点登录 |
| 45011 | 频率限制 | 登录接口做了并发保护，稍后重试 |
| 40164 | IP 不在白名单 | 调 access_token 类接口才需要；把服务器公网 IP 加到「开发设置 → IP 白名单」 |
| -1 | 系统繁忙 | 微信侧抖动，重试 |
| invalid appid（前端报） | 开发者工具里 AppID 与 manifest 不一致 | 重新导入项目，或检查 `manifest.json` |

## 九、接入检查清单

- [ ] 主体已确定（企业 / 个体户）
- [ ] 小程序已注册，能登录后台看到 AppID
- [ ] AppSecret 已拿到（只显示一次）
- [ ] `./ops/use-wechat.sh` 跑通，输出「凭据有效」
- [ ] 后端 `/api/auth/login` 不再返回「未配置」
- [ ] 开发者工具登录的是管理员/开发者微信
- [ ] 导入 `dist/build/mp-weixin`，勾选「不校验合法域名」
- [ ] 真机预览能进首页、能登录（后端日志出现真实 openid）
- [ ] 域名已备案、HTTPS 可用、服务器域名已配置（上线必需）
- [ ] 认证 / 类目 / 备案 / 隐私指引 四件套（上线必需）

## 十、做完之后，代码里发生了什么

| 位置 | 变化 |
| --- | --- |
| `apps/*/src/manifest.json` | `mp-weixin.appid` = 你的 AppID |
| `ops/.env` | `WX_USER_APPID` / `WX_USER_SECRET` |
| 后端环境变量 | 启动时注入给 Spring Boot（`WechatProperties`） |
| `AuthService.login` | 用 `code2session` 换真实 openid，不再走 mock |
| `utils/auth.ts` | 先 `uni.login` 真实登录，失败才回退 mock |

上线前记得：`app.mock-login=false`、`app.mock-pay=false`（改 `server/src/main/resources/application-prod.yml` 已有，用 `--spring.profiles.active=prod` 启动即可）。
